# HaYTooL - GitHub Pages Web Sitesi (websites Branch)

Bu dal (`websites`), **HaYTooL** projesinin GitHub Pages üzerinde yayınlanan resmi tanıtım web sitesi kaynak dosyalarını barındırır.

## 📁 Dizin İçeriği
- `index.html`: Kedi temalı ve YouTube renk uyumlu ana tanıtım sayfası.
- `style.css`: Modern karanlık mod, glassmorphism ve animasyonlu Vanilla CSS stilleri.
- `app.js`: Etkileşimli sekme yönetimi, ekran görüntüsü lightbox büyütme ve çift dil (TR/EN) mantığı.
- `assets/`: Logo, kedi maskotu ve uygulama ekran görüntüleri.
- `.nojekyll`: GitHub Pages'in Jekyll derlemesini atlaması için gerekli dosya.
