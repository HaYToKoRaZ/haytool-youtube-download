🪟

Windows İçin Başlatma

Klasör içindeki Multimedia HaYTooL.exe dosyasını çift tıklatarak sistem tepsisinde başlatabilirsiniz.

Tekil birleşik masaüstü oynatıcısını, tepsi modunu veya sessiz servisi başlatmak için:

"Multimedia HaYTooL.exe"  |  .\haytool --tray-only  |  .\haytool silent

Dashboard varsayılan olarak http://localhost:4141 adresinde açılır.

🐧

Linux / macOS (Unix)

Terminalden çalıştırma izni verin ve başlatma scriptini çalıştırın:

chmod +x baslat.sh
./baslat.sh

Çift işletim sistemli (Dual-boot) sistemlerde config parametreleri otomatik izole edilir.

💻

Gelişmiş CLI & Terminal Komut Desteği

HaYTooL'u arayüz açmadan terminalden (CMD / PowerShell / Bash) veya Sistem Tepsisi "Konsol Çıktısı" penceresinden doğrudan kontrol edebilirsiniz:

Terminalden doğrudan indirme veya Oyun Modu örneği (tıklayıp kopyalayın):

"Multimedia HaYTooL.exe" pd "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
